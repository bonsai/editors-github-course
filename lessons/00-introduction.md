# 00. はじめに

ようこそ！「編集者のためのGitHub講座」へ。

## この講座で得られること

GitHubは「エンジニアのツール」というイメージが強いですが、実は**文章を書く人・編集する人**にも非常に強力なツールです。

- 原稿の履歴がすべて残る（「あの版どこ行った？」がなくなる）
- 複数人で同時にレビューできる
- 変更箇所が差分で一目でわかる
- Issueでタスクと進捗を可視化できる

この講座では、**ブラウザだけで**これらの基本を身につけます。

## 前提知識

- 特になし（Gitやプログラミングの知識は不要）
- GitHubアカウントがあるとスムーズです（なくてもレッスン中に作れます）

## 進め方のコツ

1. **実際に手を動かす**ことを最優先してください
2. わからない用語が出てきたら、とりあえず先に進んでOK
3. 各レッスン末尾の「やってみよう」は必ずやってみてください
4. 失敗しても大丈夫です。GitHubは履歴が残るので元に戻せます

## 用語の心構え

| 用語 | 編集者向けのイメージ |
|------|---------------------|
| リポジトリ (Repository) | 原稿フォルダ・プロジェクトフォルダ |
| コミット (Commit) | 「この版を保存」ボタン |
| ブランチ (Branch) | 作業用の下書きコピー |
| Pull Request (PR) | 「この原稿をレビューしてください」の依頼書 |
| Issue | タスクメモ・原稿管理票 |
